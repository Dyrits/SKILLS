## Method

Real runs, not simulations: each run is a `claude -p` child in an empty temporary workspace, with the case's `fixture.sh` as scaffold where the case has one, and only this plugin loaded (or no plugin, for the baseline arm). Graders are the case's `graders/*.md`: `tool_used` and `regex` checks computed from the trace and files, and `llm` rubrics voted three times by the judge. A `tool_used: Skill` grader is an indicator only and is not scored in a two-arm run. Raw results (`aggregate-result.json`, `report.html`, `vc-upkeep.json`) stayed local in the ignored `evaluations/results/`; the run traces were in temporary directories and are gone, so this report rests on the grader verdicts and the final replies the result file keeps.

The run covered the `upkeep` and `version-control` tags together (24 cases, 492 seconds, USD 14.63). Its version-control half failed on an account session limit and is reported separately.

## Rerun after the grader fix

A first rerun loosened the rubric (any language, remarks on tasks 4 and 5 allowed). It scored 0.83 in both arms (Δ 0.00): the baseline also covered tasks 1 to 3, and one with-plugin failure was a correct reply the judge split on (FAIL PASS FAIL).

The replies differed in what they recommended. Every baseline reply proposed moving task 1 or task 3 straight to `ready`. Every with-plugin reply recommended `to-evaluate` (or asked the maintainer) instead, as the skill's state machine prescribes: an untriaged task enters `to-evaluate`, and a lifted hold returns there. ## Limits and open points

- Likely cause, not confirmed (the judge records votes, not reasons): the rubric says to leave out task 5 (ready), and every with-plugin reply added an "also worth a look" note on task 5 (its body says "Brief attached." with no brief) and on task 4 (still `ready` after its release shipped). Those notes are defensible triage, so the rubric is stricter than the skill's intent.
- Next step: allow a separate note on ready tasks with a real defect, and fail only when task 5 is presented as needing triage; or fix the fixture so task 5 carries a real brief. Then rerun the positive case.
- `nothing-changed` checks that `Edit` was never called. It passes in both arms.
- One with-plugin run and all three baseline runs answered in French. Some replies came back in French in both arms (see the case notes), although the prompts and fixtures are English. Context from outside the plugin reaches the isolated runs, which matches the open question in the skill-upkeep handoff about organization instructions skewing evaluations.
