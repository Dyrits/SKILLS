## Method

Real runs, not simulations: each run is a `claude -p` child in an empty temporary workspace with only this plugin loaded (or no plugin, for the baseline arm). Graders are the case's `graders/*.md`: `tool_used` and `regex` checks computed from the trace and files, and `llm` rubrics voted three times by the judge. A `tool_used: Skill` grader is an indicator only and is not scored in a two-arm run. Raw results (`aggregate-result.json`, `report.html`) stayed local in the ignored `evaluations/results/`.

## Limits and open points

- The case expects a map in the first turn, while the prompt names no destination or capability; the skill reasonably asks first. Either give the destination and capability name in the prompt, or grade the first turn as a question round.
- The rubric's `focus: trace` lets the judge pass a baseline that described a graph without writing one; grade the map file instead once the case writes one.
- The debugging run mentioned the user's employer in a question, so organization-level instructions reached the isolated run; results on another account may differ.
