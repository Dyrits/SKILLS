## Method

Real runs, not simulations: each run is a `claude -p` child in an empty temporary workspace, with the case's `fixture.sh` as scaffold where the case has one, and only this plugin loaded (or no plugin, for the baseline arm). Graders are the case's `graders/*.md`: `tool_used` and `regex` checks computed from the trace and files, and `llm` rubrics voted three times by the judge. A `tool_used: Skill` grader is an indicator only and is not scored in a two-arm run. Raw results (`aggregate-result.json`, `report.html`, `vc-upkeep.json`) stayed local in the ignored `evaluations/results/`; the run traces were in temporary directories and are gone, so this report rests on the grader verdicts and the final replies the result file keeps.

The run covered the `upkeep` and `version-control` tags together (24 cases, 492 seconds, USD 14.63). Its version-control half failed on an account session limit and is reported separately.

## Limits and open points

- Likely cause of the rubric failures, not confirmed (the judge records votes, not reasons): the skill's round covers every code topic, including ones with no evidence in `src/` (fakes versus mocks, new dependencies, reviewer feedback), and those recommendations read as generic best practice, which the rubric's FAIL clause forbids. The rubric also asks for "the reason behind each rule" and two of three runs asked for it once in the preamble rather than per question.
- Next step: split the rubric into what the skill must do (questions grounded in `src/`, nothing written) and what it may add (topics without code evidence), then rerun the positive case. A `file_exists`-style check that no conventions file was written would separate the arms on its own.
- One run with the plugin recommended "using the `setup` skill" for tool-checkable rules. The skill names `setup` only as a focus (`code (review, setup)`), so the model likely read it as a skill name; a single run, worth watching.
- One baseline run answered in French. Some replies came back in French in both arms (see the case notes), although the prompts and fixtures are English. Context from outside the plugin reaches the isolated runs, which matches the open question in the skill-upkeep handoff about organization instructions skewing evaluations.
