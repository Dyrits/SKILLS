# Repository maintenance

These guides describe how to maintain this skills repository. They are shared documentation for contributors and agents.

- [Standard installation wording](./standard-installation-wording.md) defines the commands and wording used when documenting installation.
- [Writing skill documentation](./writing-documentation.md) defines page structure, provenance, and synchronization checks.
- [Writing evaluations](./writing-evaluations.md) defines the test-case format and coverage requirements.
- [Skill invocation](./invocation.md) defines descriptions, metadata, dependencies, and missing-skill handling.

Agent helpers, installed skills, and session handoffs remain in `.agents/`.
