Architecture review for orders-service

Collapse the Order intake pipeline

Badge: Strong. Files: src/orders/OrderHandler.ts, OrderValidator.ts, OrderRepo.ts.

Problem: Order intake is spread across three shallow modules; the interface is nearly as wide as the implementation.

Solution: One Order intake module with a single entry point; validation and persistence move behind the seam.

Fold the PricingClient into Order intake

Badge: Worth exploring. Files: src/orders/PricingClient.ts. Contradicts ADR-0007, but worth reopening because pricing leaks into OrderRepo.

Top recommendation: Collapse the Order intake pipeline.
