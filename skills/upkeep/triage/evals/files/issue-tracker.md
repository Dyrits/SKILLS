# Issue tracker

Local tracker for the Orchard reports project.

- Tasks are Markdown files in `tasks/`. The task id is the file name without `.md`.
- Each task starts with `Title:`, `Created:`, `Category:` and `Status:` lines. A task with no `Status:` line is untriaged.
- Comments are appended under a `## Comments` heading at the end of the file.
- Closing a task as not planned sets `Status: not-planned`; finished delivery sets `Status: done`.
- External pull requests are not a request surface for this project.
- Rejected enhancements are recorded in `documentation/out-of-scope/`.
