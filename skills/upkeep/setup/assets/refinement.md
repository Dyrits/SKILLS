## Project documents and publication

Find the project documents (requirements, backlog, working state, changelog, glossary, conventions, decision records, and each capability's requirements, specifications, draft, and task files) through `AGENTS.md`, which names each one and where it lives. Use them in place, and keep one authoritative copy of each; everything else points to it.

Reading remote records through the configured access method is always allowed. Creating or updating remote records needs authorization.
