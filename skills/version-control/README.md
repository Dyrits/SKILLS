# Version control

Branches, worktrees, and their history.

- [work-in-tree](./work-in-tree/SKILL.md): Carry out work in an isolated checkout with a verified return destination.
- [sync-tree](./sync-tree/SKILL.md): Transfer committed work to the verified corresponding local branch.
- [rebase](./rebase/SKILL.md): Rebase local branches with recovery records, checks, and separately approved publication.
- [resolve-merge-conflicts](./resolve-merge-conflicts/SKILL.md): Resolve conflicts by intent and finish the operation.
