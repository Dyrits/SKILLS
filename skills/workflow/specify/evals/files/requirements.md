# Requirements (Quillmark Analytics, invented example)

## Global

- G1. Personal data is exported only for users who gave export consent.
- G2. Every export action is written to the audit log with the user and timestamp.
- G3. Interface text is available in English and Dutch.

## Reports capability

- R1. Reports load in under 2 seconds for up to 10,000 rows.
- R2. Only viewers with access to a report may see its data.
