# Reference

Reusable disciplines reached by the model or the user.

- [refine](./refine/SKILL.md): Resolve decisions through questions asked in dependency-aware rounds.
- [domain-modeling](./domain-modeling/SKILL.md): Sharpen vocabulary and record qualifying decisions and review guidelines.
- [codebase-design](./codebase-design/SKILL.md): Design deep modules with clear interfaces and useful seams.
- [documentation](./documentation/SKILL.md): Maintain technical documentation and the shared project-document model.
- [writing-for-agents](./writing-for-agents/SKILL.md): Write agent instructions with clear steps, completion criteria, and references.
- [wizard](./wizard/SKILL.md): Generate a guided script for steps only a human can perform.
- [unslop](./unslop/SKILL.md): Edit prose to remove filler and recurring AI writing patterns.

## Not in the plugin

- [classify](./classify/SKILL.md): Classify safe-to-send text with classifier.dev and retain uncertain results for review. Model-invoked.
- [scriptbook](./scriptbook/SKILL.md): Reuse saved scripts before writing new ones, maintaining project and global indexes. Model-invoked.
