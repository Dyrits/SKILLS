# Reference

Disciplines that shape how another task is done. They produce no result of their own; other skills call them, and you or an agent can also reach them directly.

- [interview](./interview/SKILL.md): Settle decisions through rounds of questions, each with a recommended answer.
- [codify](./codify/SKILL.md): Draft the project's code conventions from how its code is written, confirm each rule and its reason, or audit existing conventions.
- [delineate](./delineate/SKILL.md): Settle what the project's words mean, against the glossary, the code, and concrete scenarios.
- [design-modules](./design-modules/SKILL.md): Design deep modules with clear interfaces and useful seams.
- [document](./document/SKILL.md): Maintain technical documentation and the shared project-document model.
- [write-for-agents](./write-for-agents/SKILL.md): Write agent instructions with clear steps, completion criteria, and references.
- [unslop](./unslop/SKILL.md): Edit prose to remove filler and recurring AI writing patterns.
- [memorize](./memorize/SKILL.md): File lessons where the next agent will look, and recall them before redoing work, including saved scripts.
