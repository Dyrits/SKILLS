# Reference

The reusable layer other skills invoke or cite: shared vocabulary and primitives that run beneath the flows.

## Model-invoked

- **[grilling](./grilling/SKILL.md)**: The interview primitive: rounds, the frontier, facts are the agent's job and decisions are yours. Run by `grill-me`, `grill-with-docs`, `triage`, `wayfinder`, `improve-codebase-architecture`.
- **[domain-modeling](./domain-modeling/SKILL.md)**: Actively build and sharpen a project's domain model: challenge terms, stress-test with scenarios, update `CONTEXT.md` and ADRs inline.
- **[codebase-design](./codebase-design/SKILL.md)**: The deep-module vocabulary (module, interface, depth, seam) for designing a module's shape.
- **[writing-for-agents](./writing-for-agents/SKILL.md)**: How to write any document an agent consumes: skills, AGENTS.md/CLAUDE.md, docs reached by a pointer.
- **[wizard](./wizard/SKILL.md)**: Generate an interactive bash wizard that walks a human through steps only they can perform.
