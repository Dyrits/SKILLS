# Shop

Sells goods to customers online and ships them from one warehouse.

## Language

**Order**:
A customer's request to buy one or more items, placed at checkout.
_Avoid_: Purchase, basket

**Cancellation**:
The ending of an entire Order before it ships.
_Avoid_: Void, abort

**Customer**:
A person or organization that places Orders.
_Avoid_: Client, buyer
