# Sheet music Resources

## Knowledge

- [Book: _Music Reading for Beginners_ by Ilse Marchetti (invented title)](https://example.test/music-reading)
  Chapter-by-chapter introduction to the staff, note names, and rhythm. Use for: note names and note durations.
- [Article: "Why you should read the rhythm first" (Harbor Keys Journal, invented)](https://example.test/rhythm-first)
  Argues for practising rhythm apart from pitch. Use for: designing rhythm drills.

## Wisdom (Communities)

- [r/pianolearning](https://example.test/r/pianolearning)
  Moderated beginner forum. Use for: feedback on posture, fingering, and practice habits.
