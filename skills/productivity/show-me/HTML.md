# HTML artifacts

Use one focused diagram, infographic, or short slide deck, whichever explains the point with the least navigation.

1. Write `show-me-{topic}.html` in a writable artifact location that follows the workspace's conventions, and include the styles and scripts it needs for local viewing.
2. Match an existing product's colours, type, spacing, and components when the topic concerns that product; otherwise use a simple, readable design.
3. Use real labels and data from the conversation or source, and mark illustrative values and proposed states.
4. Support desktop and mobile widths with legible text and clearly labelled relationships; add interaction only when it helps explain a state or comparison.
5. If browser tools are available, inspect the result at desktop and mobile widths and fix clipped content, unreadable labels, and broken interactions before delivering it.
6. Open the file using the available browser or system opener, such as `open` on macOS or `xdg-open` on Linux, and provide a clickable file link.

Done when the artifact shows the intended point and opens successfully.
If preview or opening tools are unavailable, provide the file link and state which checks you could not perform.
