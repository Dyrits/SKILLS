# Member booking

## Destination

A decision-complete route to replacing the Granite Peak Climbing Gym's paper sign-up sheets with online slot booking for members, ready to hand to specification.

## Notes

Consult `interview` and `delineate` for interviews. Execution is not approved: this map produces decisions, not code. Standing preference from the gym manager: members must never need an app install.

## Decisions so far

- [Choose the booking model](tasks/01-choose-booking-model.md): members book fixed 90-minute slots with a per-slot capacity, not free-form time ranges.

## Not yet specified

- Instructor-led classes and how they share capacity with open climbing.
- Payment: whether a booking can require a deposit.

## Out of scope

- Point-of-sale for the cafe, because it shares no data with booking.
