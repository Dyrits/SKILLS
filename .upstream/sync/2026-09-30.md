## Documentation corrections

Upstream's glossary rename left a question comparing `GLOSSARY.md` to itself and an answer saying the name was unsettled.
The maintained domain-modeling page instead explains the rename and how to migrate an existing project's glossary references.

Upstream's test-driven-development page attributes refactoring execution to `code-review`, but the review skill only reports findings.
The maintained page now describes refactoring recommendations followed by a separate implementation step.
The review skill itself gains no editing phase.

The parallel-build page describes merging the integration tip without promising conflict-free fast-forwards, which concurrent merges cannot guarantee.
It also records the upstream limitations around repeated reviews, tracker blockers that remain open until final merge, and tests requiring untracked resources.
