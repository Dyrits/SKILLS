## Decisions

- Name `prune`, matching the single-verb upkeep names (`codify`, `triage`). The user was told a rename is cheap and has not objected.
- A missing reference is never enough to delete: each candidate is classified Used, Unused, or Uncertain against the reach table in `SKILL.md`, and Uncertain goes to the user in one round.
- Removal is by hand in batches of one kind, each staged as a checkpoint after the checks pass, bisected on failure. Detectors' automatic fix options (`knip --fix`) are not used, so each removal keeps its own verdict.
- No commit unless the user asks; the staged diff is the result.
- Detectors run without being added to the project (`npx`, `uvx`, `go run`); a machine install needs the user's approval.
- `depcheck` (archived 2025) and Periphery (archived, gone commercial) are left out of `references/tools.md`. Its `Verified:` date is 2026-11-19.
- A bundled script covers assets because no maintained cross-language tool does; it errs toward "referenced" and only lists candidates.
