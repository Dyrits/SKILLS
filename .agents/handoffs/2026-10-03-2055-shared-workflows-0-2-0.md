## Completed changes

The planned flow is `specify → taskify → implement → code-review-and-refactor`, with decomposition optional for small work. `refine` is the general interview discipline. `iterate` develops the living application just in time, primarily using backlog, working state, and root changelog; it respects existing requirements and specifications without generating feature documents or tasks merely to run a batch.

Current names include `refine`, `specify`, `taskify`, `re-explain`, `graphify`, and `illustrate`. Obsolete entrypoints and pages were removed, not kept as invocation aliases. `graphify` retains the decision records, blocking edges, resolutions, and evolving map of upstream `wayfinder`. At the end it offers a visual once and invokes `illustrate` when accepted or already requested. Native `wayfinder:*` tracker labels remain compatibility identifiers, not command aliases.

All twelve former experimental skills now occupy purpose buckets. Their moves do not promote them. There are 47 retained skills, 32 plugin entries, and 32 human-facing pages.

The provenance audit distinguishes 29 Matt-derived skills, three other external adaptations, and 15 fork-created skills. `illustrate` derives from HumanLayer's `show-me`; `unslop` derives from Cursor pstack; `documentation` derives from a pinned Anthropic knowledge-work plugin and is extended with this fork's shared document model. Removed upstream skills were not restored. Attribution uses primary archives and retained history, not matching names alone.
