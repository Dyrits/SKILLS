- `capture-review-state.py`: Capture an unstaged Git review patch, scope, and changed-file contents outside the repository. Usage: `python3 .agents/scripts/capture-review-state.py OUTPUT BASE [REPOSITORY]`. Needs: Python 3 and Git.
- `generate-skill-manifests.py`: Write the APM manifests: an `apm.yml` beside every skill that calls or hands over to another skill here (one `git: parent` sibling dependency per reference), and the root `apm.yml` that publishes every skill as `<name>@dyrits`; `--check` lists missing, stale, or orphaned manifests. Usage: `python3 .agents/scripts/generate-skill-manifests.py [--check] [REPOSITORY]`. Needs: Python 3.
- `stage-eval-run.py`: Stage a skill's evals for a dry run: one `prompt.txt` per eval (expectations withheld from the runner), the skill's fixtures, and a grading sheet for the grader. Usage: `python3 .agents/scripts/stage-eval-run.py WORKSPACE SKILL_DIRECTORY [KIND ...]`. Needs: Python 3.
- `update-references.py`: Replace literal text across listed or searched files, printing a `git apply` diff (or Codex apply_patch with `--format apply-patch`), or writing the files with `--apply`. Usage: `python3 .agents/scripts/update-references.py --replace OLD NEW [--search [--exclude PATHSPEC]... | -- PATH...] [--apply]`. Needs: Python 3; Git for `--search`.
